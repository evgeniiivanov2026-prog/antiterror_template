# antiterror_template

WordPress theme **Антитеррор 1.12** for the journal site. Drop-in replacement for JournalX.

## Install

Copy `antiterror-press/` to `wp-content/themes/antiterror-press` and activate it.

## Base

The theme keeps the v1.11 architecture (`at_*` PHP helpers, paper/ink tokens, fighter directory, media vault, BPLA feed, milestone index) and adds a nonce-protected REST layer for live search, AJAX journal filtering, and the contact popup.

Reference zips in this repository stay untouched:

- `antiterror-press-v1.11-vehi.zip` — core
- `journalx.zip` — related posts / share / infinite feed ideas
- `root-akademicheskiy.zip` — scroll reveal
- `abc-pagination.zip` — milestone index companion
